# Submission artifacts

- `screenshots/`: screenshots of the whole final chat with the manager.
- `decision-log.md`: the agent's decision log of the final conversation, one line per message
  (what came in, what the agent understood, what it decided, what it sent). Copied from
  `logs/decisions.md`, which was cleared before the final run. Log times are London time
  (GMT); screenshots show Kyiv time (GMT+2).
- `NOTES.md`: the full history of what broke during testing and how each problem was fixed.
  The short submission notes are in the root [NOTES.md](../NOTES.md).
